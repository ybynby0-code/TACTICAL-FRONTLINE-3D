# Production roadmap

## Milestone 1 — Playable vertical slice
- Import final player rig, one hero, one weapon and one test arena
- Third-person/first-person camera decision and movement tuning
- Weapon recoil, hit feedback, reload animation and damage feedback
- One complete hero ability with VFX/SFX
- HUD, pause/settings and controller/mobile input

## Milestone 2 — Core match
- Team assignment, spawn selection and round flow
- Objective mode and scoreboard
- Server-authoritative damage, cooldowns, kills and match results
- Network replication, prediction and reconciliation

## Milestone 3 — Accounts and progression
- Supabase Auth
- Player profile, stats and inventory metadata
- Server-side validation for XP/rewards
- RLS review and security advisor pass

## Milestone 4 — Content
- 3 launch heroes with distinct roles
- 3 weapons, 1 map, polished animation/VFX/audio
- Accessibility, localization and onboarding

## Milestone 5 — Release gates
- Automated edit-mode and play-mode tests
- Android/Windows build validation
- Performance budgets and device profiling
- Load tests, abuse tests, anti-cheat review
- Privacy policy, terms, crash reporting and rollback plan
