# TACTICAL FRONTLINE 3D

Unity 2022.3 LTS+ starter scaffold for a stylized 3D hero shooter.

This repository contains the Alpha 2 source package. It is a development scaffold, not a compiled or release-ready game. See `Docs/SCENE_SETUP.md` for setup and `Docs/ROADMAP.md` for planned milestones.

Included: player movement, third-person camera, health/damage, weapon fire/reload, hero ability framework, practice target, match state/team model, and a Supabase schema starter.

Not included: finished character/map assets, production matchmaking, authoritative multiplayer server, anti-cheat, or validated mobile/PC builds.

Do not put Supabase service-role keys in a game client.
